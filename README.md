🚀 How to Play

Go to the Releases section of this repository

Download the latest ZIP build

Extract the ZIP file

Launch the game

Login

Scan your room using AR

Place the basketball setup

Play and enjoy!

✨ Features

🎧 Sound System – immersive audio feedback

🎨 Clean & Stylized UI – minimal and user-friendly design

🏆 Leaderboard – compete and compare scores

📊 Analytics – track player activity and performance

📢 Ads Integration – in-game ads support

🏅 Achievements System – unlock rewards as you play

🕶️ AR Environment Scanning – real-world placement using AR

🛠 Built With

Unity

AR Foundation

Unity Gaming Services (UGS)

📌 Notes

Ensure your device supports AR

Play in a well-lit environment for better tracking

Internet connection required for login, leaderboard, analytics, and ads
